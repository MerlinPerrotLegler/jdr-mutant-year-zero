# Menace : Ver Tueur

*2× la taille d'un mutant, grosseur d'une cuisse, multiple rangées de dents. Chasse en sous-sol.*

| Attribut | Valeur |
|---|---|
| Vigueur | 8 |
| Agilité | 3 |
| Combat | 3 |
| Furtivité | 5 (sous terre) |
| Déplacement | 5 (sous terre) |

**Arme :** mâchoire (dégâts 2). Si réussite → traîne sous terre (+3 aux attaques suivantes, test Force pour se libérer).

**Comporte** : ne fuit jamais.
