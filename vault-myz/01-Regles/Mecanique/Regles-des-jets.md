# Mécanique : Règles des Jets de Dés

## Composition du jet

| Dé | Couleur | Quantité |
|---|---|---|
| Dés de base | Jaune | Valeur actuelle de l'attribut lié |
| Dés de compétence | Vert | Niveau de compétence (0 = pas de dés verts) |
| Dés d'équipement | Noir | Bonus d'équipement de l'objet utilisé |

**Réussite :** au moins un / (6).
**Prouesse :** chaque / supplémentaire au-delà du premier.

## Compétence à 0

On peut toujours faire un test — en lançant uniquement les dés de base. **Exception :** les compétences de spécialiste requièrent au moins le niveau 1.

## Forcer le jet

Relancez tous les dés qui n'affichent ni /, ni =, ni ⚙. **Une seule fois.**

- Chaque = (dé de base) = **1 point de traumatisme** sur l'attribut utilisé + **1 PM gagné**.
- Chaque ⚙ (dé d'équipement) = **-1 bonus d'équipement** de l'objet.

## Table de difficulté

| Difficulté | Modificateur |
|---|---|
| Jeu d'enfant | +3 |
| Facile | +2 |
| Simple | +1 |
| Normal | 0 |
| Exigeant | -1 |
| Difficile | -2 |
| Démentiel | -3 |

## S'entraider

Un allié annonce qu'il aide avant le jet → **+1** par aidant (max 3 aidants = +3 maximum). L'aidant perd son action en conflit. **Interdit pour les compétences de spécialiste.**

## Jets opposés

Les deux parties lancent simultanément. Pour triompher : avoir réussi ET avoir plus de / que l'adversaire. Seul l'agresseur peut forcer le jet.

## Dés normaux (sans dés spéciaux)

- **Dés de base :** 1 = =, 6 = /
- **Dés de compétence :** 1 normal, 6 = /
- **Dés d'équipement :** 1 = ⚙, 6 = /
