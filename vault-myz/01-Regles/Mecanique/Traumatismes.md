# Mécanique : Traumatismes

## 4 types de traumatismes

| Traumatisme | Attribut | Cause |
|---|---|---|
| Dégâts | Vigueur | Attaques physiques |
| Épuisement | Agilité | Faim, efforts, venin |
| Confusion | Intellect | Peur, drogues, sommeil |
| Doute | Empathie | Manipulation, peur, doute |

**Brisé :** un attribut tombe à 0.

## Récupération

- **Dégâts** : manger + reposer (quelques heures).
- **Épuisement** : boire + reposer.
- **Confusion** : dormir 4h.
- **Doute** : compagnie d'autres mutants.

## Blessures critiques

Quand la Vigueur tombe à 0 → tirer D66 sur la table (p. 90-91).

## Soins

- Test de Soins pour qu'un personnage Brisé récupère 1 point de Vigueur par /.
- Test de Soins pour stabiliser une blessure critique (sauve la vie).
