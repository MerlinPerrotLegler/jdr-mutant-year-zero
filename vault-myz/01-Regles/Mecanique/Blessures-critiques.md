# Mécanique : Blessures Critiques

Quand les dégâts **Brisent** un personnage (Vigueur à 0), il subit une blessure critique : tirer D66 sur la table des blessures critiques.

## Dégâts Atypiques

Certains effets (Brisé par faim, poison non soigné) infligent des **dégâts atypiques** — même mécanique mais source différente.

## Notes MJ

> Utiliser les blessures critiques pour dramatiser les combats difficiles.
