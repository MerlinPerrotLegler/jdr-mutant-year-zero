# Mécanique : Utiliser une Compétence

Lancez un nombre de dés selon la couleur :

| Type de dé | Couleur | Source |
|---|---|---|
| Dés de base | Jaune | Valeur de l'attribut lié |
| Dés de compétence | Vert | Niveau de compétence |
| Dés d'équipement | Noir | Bonus d'équipement |

**Réussite :** au moins un 6 (ou symbole /).

**Test opposé :** les deux parties lancent, celui qui obtient le plus de / l'emporte.

## Forcer un jet de dés

Relance tous les dés qui n'affichent pas /, = ou ⚙.

- **= sur dé de base (forcé)** : 1 point de traumatisme dans l'attribut + 1 PM gagné.
- **⚙ sur dé d'équipement (forcé)** : bonus d'équipement de l'objet diminue de 1.
