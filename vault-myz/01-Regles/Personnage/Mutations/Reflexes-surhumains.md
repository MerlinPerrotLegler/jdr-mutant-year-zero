# Mutation : Réflexes Surhumains

- Initiative +2 par PM (avant le jet ou pendant le combat en perdant sa manœuvre).
- Attaquer une 2e fois dans le même tour (1 PM, pas de manœuvre supplémentaire). **(A)**
- Esquiver : 1 PM = -1 dégât reçu (avant le jet d'armure). **(R)**
