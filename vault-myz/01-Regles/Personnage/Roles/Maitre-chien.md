# Rôle : Maître-chien

*Le compagnon canin. Attribut clé : Agilité. Compétence de spécialiste : Lâcher le chien.*

## Création

- **Attributs :** 14 points (Agilité peut atteindre 5).
- **Compétences :** 10 points + Lâcher le chien min. 1.
- **Talents :** Chien de combat / Le meilleur ami du mutant / Limier.
- **Équipement :** D6 balles, D6 bouffe, D6 eau. Arme : chaîne de vélo / couteau de fortune / fronde / fusil de fortune.

## Lâcher le chien (Agilité)

Utilise la Vigueur du chien comme dés de base, niveau Lâcher le chien comme dés de compétence.

**Le chien :** suit les mêmes règles qu'un mutant pour les dégâts. Si Vigueur = 0 → mort. Compassion pour récupérer l'Empathie.

**Noms chiens :** Grim, Grock, Fingo.
