# Talents : Résumé par Rôle

## Talents de Caïd
- **Commandant** : +2 quand la bande se bat pour vous.
- **Détrousseur** : +2 aux jets de Commandement pour racketter.
- **Flingueurs** : votre bande a des armes à feu.

## Talents de Chroniqueur
- **Agitateur** : +2 quand vous Inspirez quelqu'un pour Tirer/Combattre.
- **Toubib** : +2 aux Soins pour blessures critiques.
- **Troubadour** : une fois/séance, représentation → chaque / = D6 balles ou bouffe.

## Talents de Combinard
- **Info croustillante** : obtenez une info compromettante sur un PNJ.
- **Magouilleur** : Conclure un marché donne le double.
- **Vicelard** : Manipulation inflige +1 doute.

## Talents de Fracasseur
- **Coup vicieux** : mains nues → 2 dégâts au lieu de 1.
- **Cruel** : Intimidation inflige +1 doute.
- **Passage en force** : utilisez Déplacement avec Vigueur.

## Talents de Larbin
- **Blasé** : +2 Endurance si vous avez du doute (pas d'autre traumatisme).
- **Dur à cuire** : +2 Tenir le coup si vous avez des dégâts.
- **Rebelle** : chaque / en Endurance = +1 à votre prochaine action.

## Talents de Maître-chien
- **Chien de combat** : +2 quand vous utilisez le chien au combat.
- **Le meilleur ami du mutant** : le chien vous aide en Endurance et Déplacement.
- **Limier** : +2 Lâcher le chien pour pister (réponses supplémentaires).

## Talents de Rafistoleur
- **Fou du volant** : +1 véhicules (percuter, fuir, réparer).
- **Inventeur** : +2 Système D pour créer (pas réparer).
- **Rétameur** : +2 Système D pour réparer (pas créer).

## Talents de Zonard
- **Chasseur de monstres** : +2 Observer une créature.
- **Dénicheur de Gangrène** : Trouver le chemin → prouesse chemin moins gangrené.
- **Récupérateur** : +2 Trouver le chemin, identifie tous les artefacts du secteur.

## Talents généraux (sélection)
- **Admirateur** : un PNJ vous est dévoué (créé avec la MJ).
- **Amateur de gadgets** : +2 Compréhension pour artefacts.
- **Appétit d'oiseau** : 1 ration tous les 2 jours.
- **Archéologue** : +2 Compréhension pour bâtiments Temps d'Avant.
- **Pas de reddition** : Brisé en dégâts → test Endurance pour récupérer sans Soins.
- **Plus vite que son ombre** : dégainer sans manœuvre.
- **Poids plume** : défense en corps à corps avec Agilité plutôt que Vigueur.
