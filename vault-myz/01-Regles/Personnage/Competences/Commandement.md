# Compétence de spécialiste : Commandement (Intellect) — Caïd

*Diriger votre bande, racketter, envoyer vos hommes sur des projets.*

## La bande

**Taille :** 3-4 mutants par niveau de compétence.

**Composition de base :** Fracasseurs principalement, parfois un Maître-chien et un Combinard. Armés de massues et armes improvisées.

**Bouffe/eau :** dans l'Arche, la bande se débrouille seule. Dans la Zone, c'est à vous de fournir.

## Commander

Ordres à la bande → test de Commandement. Modificateurs selon la table :

| Facteur | Modificateur |
|---|---|
| Vous offrez une récompense significative | +1 |
| La tâche est peu risquée | +1 |
| Vous effectuez la tâche avec eux | +2 |
| Aucune récompense offerte | -1 |
| Tâche visiblement très dangereuse | -2 |
| Bande en infériorité numérique | -1 |
| Bande moins bien armée | -1 |
| Bande déjà blessée | -1 |
| Bande commence à avoir faim | -1 |

**Échec :** un membre se rebelle — combat singulier obligatoire. Si vous perdez (et survivez), la bande vous abandonne. Reconstitution : quelques semaines + test de Commandement réussi.

**Réussite :** la bande exécute. Si les circonstances changent en cours de route → nouveau jet.

## Racketter

Test de Commandement (1 par séance). Pour chaque / :
- D6 balles
- D6 rations de bouffe
- 2D6 rations d'eau pure
- 2D6 doses de tord-boyaux

## Projets

La bande peut travailler sur un projet de l'Arche à votre place : remplacez la compétence requise par Commandement.
