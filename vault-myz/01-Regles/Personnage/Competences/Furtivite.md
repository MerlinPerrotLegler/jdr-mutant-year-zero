# Compétence : Furtivité (Agilité)

*Se déplacer sans être repéré, tendre une embuscade, préparer une attaque surprise.*

## Quand l'utiliser

Jet **opposé** : Furtivité contre l'Observation de l'adversaire.

Aussi pour les embuscades et attaques surprises (cf. [[Regles/Mecanique/Combat]]).

## Résultats

**Échec :** l'ennemi vous voit ou vous entend — vous perdez l'effet de surprise.

**Réussite :** telle une ombre dans la nuit, vous passez sans être détecté.

**Prouesse :** lors d'une attaque surprise, +1 à la première attaque pour chaque / supplémentaire.
