# Compétence de spécialiste : Tenir le Coup (Vigueur) — Larbin

*Encaisser les traumatismes physiques et psychologiques.*

## Quand l'utiliser

Chaque fois que vous subissez un traumatisme (quel qu'il soit). **Exception :** ne peut pas éviter les traumatismes issus d'un jet forcé.

**En conflit :** peut être utilisé autant de fois que nécessaire — ne compte pas comme une action ou une manœuvre.

## Résultats

**Échec :** la douleur est trop intense. Vous subissez le traumatisme normalement (sans effet supplémentaire).

**Réussite :** pour chaque / obtenu, 1 point de traumatisme est ignoré. Si tous les points sont éliminés → vous ne subissez rien du tout.
